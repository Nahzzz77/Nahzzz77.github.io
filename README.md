# 张涵的个人网站

AI 产品经理张涵的个人主页，采用 Mercury 设计系统（Alpine banking at blue hour）风格。

## 技术栈

- 纯 HTML / CSS / JavaScript
- 无框架、无构建依赖，打开即用

## 本地预览

直接用浏览器打开 `index.html`，或：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 目录结构

```
├── index.html       # 页面结构
├── css/style.css    # 样式
├── js/main.js       # 交互逻辑
└── assets/          # 图片资源
```
